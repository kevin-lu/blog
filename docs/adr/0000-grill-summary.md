# 点赞功能需求对齐总结

## 审查完成时间
2026-05-19

## 变更名称
`add-article-like`

## 需求背景

为博客文章添加点赞功能，让读者快速表达对文章的喜爱，同时为博主提供内容质量反馈。

## 关键决策

| 决策点 | 确认值 | ADR |
|--------|--------|-----|
| **用户类型** | 支持未登录用户点赞（基于 session_id + IP） | ADR 0001 |
| **功能范围** | 只实现点赞功能（不含收藏） | ADR 0001 |
| **数据存储** | 实时计算 `COUNT(article_likes)` | ADR 0001 |
| **限流策略** | 同一 IP 每分钟最多 10 次点赞 | ADR 0002 |
| **日志记录** | 不记录点赞操作日志 | - |

## 领域术语（CONTEXT.md）

- **点赞 (Like)**：用户对文章的喜爱表达，无需登录即可操作
- **会话 (Session)**：未登录用户的临时标识，基于浏览器 session_id 和 IP 地址组合
- **点赞计数策略**：实时计算 vs 缓存计数（本次选择实时计算）

## 架构决策（docs/adr/）

1. **ADR 0001**: 点赞功能数据模型设计
   - 独立 `article_likes` 表
   - 实时计算点赞数
   - 支持登录 + 未登录用户
   - 数据库唯一约束防重复

2. **ADR 0002**: 点赞功能限流策略
   - IP 限流 10 次/分钟
   - 使用 flask-limiter
   - 仅针对点赞 API
