## ADDED Requirements

### Requirement: 点赞按钮 UI 组件
系统 SHALL 提供点赞按钮组件，支持点赞/取消点赞操作和视觉反馈。

#### Scenario: 显示点赞按钮和计数
- **WHEN** 用户打开文章详情页
- **THEN** 页面显示点赞按钮和当前点赞数

#### Scenario: 未点赞状态
- **WHEN** 用户未对当前文章点赞
- **THEN** 点赞按钮显示为空心/未填充状态，悬停时显示点赞图标

#### Scenario: 已点赞状态
- **WHEN** 用户已对当前文章点赞
- **THEN** 点赞按钮显示为实心/填充状态（如红色爱心）

#### Scenario: 点赞成功反馈
- **WHEN** 用户点击点赞按钮且操作成功
- **THEN** 按钮变为已点赞状态，点赞数 +1，显示短暂成功提示

#### Scenario: 取消点赞成功反馈
- **WHEN** 用户点击已点赞按钮且操作成功
- **THEN** 按钮变为未点赞状态，点赞数 -1，显示短暂成功提示

#### Scenario: 点赞失败反馈
- **WHEN** 点赞操作失败（如重复点赞、网络错误）
- **THEN** 显示错误提示，按钮状态回滚

### Requirement: 点赞交互体验
系统 SHALL 提供流畅的点赞交互体验。

#### Scenario:  optimistic UI 更新
- **WHEN** 用户点击点赞按钮
- **THEN** UI 立即更新按钮状态（在 API 响应前），操作失败后回滚

#### Scenario: 未登录用户提示
- **WHEN** 未登录用户点赞成功
- **THEN** 正常完成，不强制要求登录（可选：提示"登录后永久保存点赞记录"）

#### Scenario: 加载状态显示
- **WHEN** 点赞 API 请求中
- **THEN** 按钮显示加载状态（如禁用 + loading 图标），防止重复点击

### Requirement: 响应式设计
系统 SHALL 确保点赞组件在不同设备上正常显示。

#### Scenario: 桌面端显示
- **WHEN** 用户在桌面端访问
- **THEN** 点赞按钮显示在文章标题下方或侧边，尺寸适中

#### Scenario: 移动端显示
- **WHEN** 用户在移动端访问
- **THEN** 点赞按钮适配小屏幕，易于点击
